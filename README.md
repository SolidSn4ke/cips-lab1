## Теоретическая база

Медианный фильтр - фильтр, используемый в цифровой обработке изображений и сигналов для уменьшения уровня шума.

В качестве значения для конкретного пикселя берется медианное значение для его скользящего окна

## Описание разработанной системы

### Принцип работы

Программа вызывается с двумя аргументами: путь к изображению и размер ядра. Создается копия указанного изображения, которая потом передается функциям `med_filter_native` и `med_filter_lib`. Результаты этих функций сохраняются в папку `target`

### Алгоритм

Для каждого пикселя в цикле:

1. Определить скользящее окно. Если расстояние до границы изображения меньше, чем размер ядра, то берется ближайший граничный пиксель, например, для если в скользящее окно должен попасть пиксель с координатами (-1, 0), будет взят пиксель (0, 0)
2. Все пиксели скользящего окна сортируются отдельно по каждому каналу
3. Результирующий пиксель составляется из центральных значений отсортированных массивов по каждому каналу
